# 聪明山（Raricy.com）

## 聪明山是什么网站？

聪明山（Raricy.com）是个人网站，主页 `/`，标语是"我们总将找到答案"。这里有原创故事、互动小说、博客文章、工具和讨论，也有剪贴板、图床、音频床、投票与收藏夹。

## 聪明山首页有哪些栏目？入口在哪？

| 栏目 | 入口 | 内容 |
|---|---|---|
| 故事 / 小说 | `/story` | 原创小说和互动故事 |
| 博客 / 文章 | 核心用户 `/blog`，其他读者 `/explore` | 博客文章和思考分享 |
| 工具 | `/tool` | Base 编码、Hex 查看、格式转换等 |
| 讨论 | `/chat` | 大区讨论和私聊，Core 及以上可用 |

首页的博客入口按读者角色进入站内列表或对外公开列表。

## 站外访客能读博客吗？文章有哪些公开范围？

文章有"仅站内"、"凭链接可读"、"对外公开"三档，默认仅站内。仅站内文章要求核心用户；后两档可让站外访客阅读。凭链接可读不进入公开索引；对外公开文章可以出现在 `/explore`，也允许搜索引擎收录。

文章公开后，搜索引擎或其他人可能保存副本，改回站内可见不撤回已传出的内容。

## 故事和互动小说在哪里看？

入口 `/story`，合集里有 Markdown 小说和 Cattca 互动小说，可以继续进入子合集。Cattca 创作入口在 `/tool/cattca`。

## 工具箱里能做什么？

`/tool` 有 Base 编码、Hex 查看等工具。格式转换器在 `/tool/convert`，提供图片、音视频、PDF、表格、字幕、电子书、压缩包的本地转换；Cattca 在 `/tool/cattca` 用于写和运行互动故事。

## 讨论大区和私聊有什么区别？

讨论入口 `/chat`，需要核心用户及以上。大区是公共频道，私聊是两人之间的一对一会话。评论和讨论支持图床引用、音频播放器、表情和用户名片。

## 怎么注册和成为核心用户（Core）？

注册在 `/register`，登录在 `/login`。普通账号通过有效邀请码认证后成为核心用户，可以注册时填写，也可之后完成认证；没有邀请码时联系站长。已登录普通账号和未登录访客是不同状态，登录成功不等于完成 Core 认证。

## 哪些站点功能需要 Core？

站内博客列表、讨论、评论、剪贴板、图床、音频床、投票和收藏夹要求核心用户或更高角色。本人鱼干余额、流水和鱼干市场登录后可用；签到另需 Core、未禁言及名下一篇未删除文章。故事阅读和对外公开文章有各自的公开入口，具体内容按自身公开范围判断。

## 每日签到为什么提示发布过文章后才能签到？

签到除 Core 及以上角色外，还要求名下至少有一篇未删除的文章。没有符合条件的文章时，会提示"发布过文章后才能签到"。先满足发文条件，再到 `/checkin`。

## 导航里的“日志”是个人日记吗？

`/audit` 是站点审计日志公示与申诉入口，用于查看站务记录，不是个人日记。

## 功能限额和详细指南在哪里看？

各功能自己的使用指南说明字数、数量、大小和频率限制，`/docs` 可以集中查阅。触发限频时也可看当前页面提示。知识库中各功能条目列有对应限制，不在站点概览重复维护所有数字。

## 怎么联系站长？用户协议和隐私政策在哪？

联系方式在 `/contact`；用户协议 `/terms`，隐私政策 `/privacy`。
