# 故事模块

## 故事模块支持哪些作品？入口在哪？

入口 `/story`，收录 Markdown 小说和 Cattca 互动小说。故事可以放进合集，合集可继续嵌套子合集。

## 故事合集和阅读页面的链接是什么？

根合集是 `/story/`，子合集是 `/story/<合集路径>/`，作品是 `/story/<合集路径>/<故事id>`。例如 `/story/长篇/科幻/` 是合集，`/story/长篇/科幻/星际迷航` 是作品。

## 故事列表怎么排序？

故事与子合集一起按 `priority` 从大到小排序；优先级相同时，有简介 `description` 的排在没有简介的前面。

## 故事作者需要准备哪种文件？怎么投稿上架？

Markdown 小说用 `.md`，互动小说用 `.cattca`，文件顶部可写 YAML 元数据，后面写正文或脚本。由站长把作品放进目标合集；新子合集可提供合集名称、简介和默认作者。站点故事不是博客编辑器发文入口。

## 故事作品的 YAML 元数据怎么写？

作品文件开头用两行 `---` 包住 YAML，例如：

```yaml
---
title: 故事标题
author: 作者名
genre: 小说
ai_assisted: false
description: 一句话简介
priority: 100
ignore: false
---
```

`title` 默认用文件名，`author` 默认用合集作者；`genre` 和 `description` 默认空，`priority` 默认 0，`ignore` 默认 false，设 true 隐藏作品。`ai_assisted` 没写时继承所属合集，合集也没写则为 false；true 显示"AI辅助创作"。

## 故事合集可以指定哪些信息？

合集可提供显示名称、简介、默认作者、排序优先级和是否隐藏。名称默认目录名，简介默认空，默认作者为"未知作者"，优先级默认 0，隐藏默认 false。合集的 AI 辅助标记也可供作品继承。

## Markdown 故事支持表格、任务列表和代码高亮吗？

故事正文支持标准 Markdown、GFM 表格和任务列表。故事页的代码块没有语法高亮或复制按钮，这些是博客正文提供的能力。

## 故事正文为什么自动首行缩进？怎么取消？

普通段落首行自动缩进两字符。引用块内不缩进；可用 `<p class="u-no-indent">这一段不缩进。</p>` 对指定段落取消，适合题记或独立引言。

```markdown
> 引用块内的段落不缩进。

<p class="u-no-indent">这里也不缩进。</p>

这里恢复正常缩进。
```

## 故事链接会自动在新窗口打开吗？

故事正文链接显示为品牌色，悬停有下划线；外链不会像博客那样自动加新窗口行为。需要新窗口时在正文中显式写相应 HTML 链接。

## Cattca 互动小说和 Markdown 小说有什么区别？

Markdown 作品供连续阅读，Cattca 作品可让玩家选择、输入文字、修改变量和跳转分支。Cattca 文件顶部可用同样的 YAML 元数据，之后写 `</.../>` 命令和正文；完整命令见 Cattca 入门与脚本语法条目。
