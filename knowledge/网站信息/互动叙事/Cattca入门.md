# Cattca 互动故事入门

## Cattca 是什么？在哪里写互动故事？

Cattca 是嵌入 Markdown 的互动故事脚本语言，创作入口 `/tool/cattca`。命令块外写玩家看到的文字，命令块中写选择、变量和跳转规则；正文支持 Markdown，无需先掌握其他编程语言。

## Cattca 指令块和多条指令怎么写？

指令放在 `</` 和 `/>` 之间，多条用英文分号 `;` 分隔，可以换行书写。块外是显示给玩家的正文。

```text
你醒了。
</let hp = 100;
let mp = 50;
let 等级 = 1;/>
```

## Cattca 怎么创建和修改分数、血量等变量？

`let` 创建变量，`set` 修改已经创建的变量。变量名区分大小写，后续拼写需一致。

```text
</let 分数 = 0;
set 分数 = 分数 + 10;/>
```

## Cattca 怎么把变量值显示在句子里？

用 `apply` 输出变量或表达式，不会多出段落换行：

```text
你当前的分数是：</apply 分数 /> 分。
```

先用 `let` 声明变量，再使用同样大小写的名字。

## Cattca 怎么让玩家点击选项？

用 `input case`，选项文本放在英文引号中，选项之间用英文冒号 `:`，通过 `->` 指定选中后执行的命令。最后一个选项后不要加冒号。

```text
你要怎么做？
</input case:
'打开宝箱' -> goto 宝箱:
'继续前进' -> goto 走廊;/>
```

## Cattca 怎么记住玩家选了哪个按钮？

在 `input case` 后写变量名，选中的按钮文字会保存进去：

```text
</input case 选择:
'打开宝箱' -> goto 宝箱:
'继续前进' -> goto 走廊;/>
```

之后用 `apply 选择` 读取。分支中的执行顺序仍由跳转决定。

## Cattca 的 label、goto 和 exit 怎么配合？

`label` 定义书签，`goto` 跳到该书签，`exit` 结束脚本。每个结局末尾放 `exit`，避免继续执行下一个结局。

```text
</input case:
'打开宝箱' -> goto 宝箱:
'离开' -> goto 离开;/>
</exit/>

</label 宝箱;/>
你获得了金钥匙！
</exit/>

</label 离开;/>
你转身离开了房间。
</exit/>
```

## Cattca 怎么按血量、金币等条件跳转？

用 `if 条件 -> 命令`，例如 `</if 血量 <= 0 -> goto 游戏结束;/>`。比较支持 `==`、`!=`、`>`、`<`、`>=`、`<=`；多个条件用 `&&`（并且）或 `||`（或者）组合。

```text
</if 血量 <= 0 && 复活次数 == 0 -> goto 永久死亡;/>
```

## Cattca 怎么让玩家输入名字或文字？

先用 `let` 声明，再用 `input text` 接收输入，最后用 `apply` 显示：

```text
</let 玩家名 = "";/>
请输入你的名字：
</input text 玩家名;/>
你好，</apply 玩家名 />！
```

正文提示放在命令块外。没有先声明变量会报"变量未声明"并停止。

## Cattca 的 random 怎么生成骰子点数？

先声明变量，写 `random 变量 = 最小值 最大值`，得到包含两端的随机整数。

```text
</let 骰子 = 0;
random 骰子 = 1 6;/>
你掷出了 </apply 骰子 /> 点！
```

## Cattca 的 log 怎么调试？

`log` 输出到运行区底部的日志面板，不加入故事正文。例如 `</log "当前血量：" + 血量;/>`，用来检查变量值和执行位置。

## Cattca 注释怎么写？

用 `/* 备注 */`，可以放在正文或命令块中。注释不执行、不显示在故事输出里，不能嵌套。

```text
/* 这里是第二关 */
</let 钥匙数量 = 0; /* 尚未找到钥匙 */ />
```

## Cattca 正文支持哪些 Markdown 排版？

可以写 `**粗体**`、`*斜体*`、`# 大标题`、`## 中标题`、`- 列表项`、`> 引用` 等 Markdown。命令在正文间控制互动流程。

## Cattca 变量显示不出来或选项没出现怎么检查？

变量先确认 `let` 声明和大小写，`hp` 与 `HP` 不同。选项检查英文引号、英文冒号、`->`、命令块是否闭合；最后一个选项后不要留冒号。多条命令必须用分号分开，换行不能代替分号。

## 有没有能直接运行的 Cattca 故事模板？

下面的 Cattca 入门故事模板包含变量、选项、分支和文字输入。复制到 `/tool/cattca`，点击"运行脚本"，再按需要修改故事正文。

```text
# 你的故事标题

你站在一个分岔路口。
</let 血量 = 100;
let 金币 = 0;
let 名字 = "冒险者";
input case:
'向左走' -> goto 左路:
'向右走' -> goto 右路;/>

</label 左路;/>
你走进小径，找到一个宝箱。
</set 金币 = 金币 + 50;/>
获得了 50 金币。当前金币：</apply 金币 />
</exit/>

</label 右路;/>
你遇到友善的旅人。
请输入你的名字：
</input text 名字;/>
很高兴认识你，</apply 名字 />！
</exit/>
```
