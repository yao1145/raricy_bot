# Markdown 编辑器

## 博客和云剪贴板用的编辑器一样吗？

博客发文 `/blog/upload` 与云剪贴板 `/clipboard/upload` 共用 Markdown 编辑器，快捷键和绝大多数按钮相同。公式按钮只在云剪贴板提供，博客没有公式按钮。

## 手机上的编辑器工具条为什么只有几个按钮？

窄屏 ≤767px 时，首行保留表情、上传图片、插入引用；标题、粗体、斜体、删除线、链接、列表、缩进、引用、代码、表格、撤销 / 重做、导出等在"更多工具"里。云剪贴板还包含公式。

点击"更多工具"展开，再点收起；开关位置不变，按钮排不下会换行。宽屏 ≥768px 直接显示完整工具条，没有这个开关。

## 编辑器里 Enter 和 Shift+Enter 有什么区别？

Enter 会续写列表和引用标记；光标位于一对空链接括号中时，可能多补一个空行。Shift+Enter 只插入一个换行，适合地址、歌词等连续换行。

普通段落中单个换行显示为换行，连续两个换行成为新段落，无需补 `<br>` 或行尾空格。代码块按自身内容排版。

## 编辑器怎么插入音频、剪贴板、投票和收藏夹？

点"插入引用"，切换到相应类别，挑选已有内容。插入的是 `[@…]`，例如剪贴板 `[@a1b2c3d4]`、投票 `[@vOtE12345]`、收藏夹 `[@123456]`、音频 `[@音频/AbCdEf1234]`。

## 编辑器插入图片为什么不是图片 ID 引用？

通过"上传图片"新传，或通过"插入引用"挑图床已有图片，插入的都是标准 Markdown：`![文件名](/api/images/ID/raw)`。它与手写 `[@10位图片ID]` 的语法不同，都会显示图片。

## 预览、导出和发布后的内容引用规则一样吗？

相同：剪贴板 / 投票 / 图床图片最多替换 50 处，收藏夹最多 3 张，音频最多 3 个；需要读取内容的引用一轮最多 50 个；展开后总长度 ≤ 500,000 字符。超限引用在预览中也保留原文。

预览里的投票只展示，无法提交；预览不展开表情包和用户名片，它们只在评论、讨论中生效。

## 编辑器的标题和表格按钮怎么用？

标题下拉选择级别，选"正文"可去掉标题标记 `#`。表格按钮插入表头、分隔行和一行内容的三行骨架，再自行补充数据行。

## 能在预览里直接编辑正文吗？手机能并排预览吗？

预览区只用于查看。正文在编辑区修改，预览随之更新。窄屏不提供并排模式，宽屏可以并排。

## 编辑器怎么导出 HTML 或 PDF？

点工具条的"导出"，可导出 HTML，也可通过打印另存为 PDF。导出中的引用仍受预览和发布时相同的数量、权限和长度规则约束。
