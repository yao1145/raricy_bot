# 收藏夹

## 怎么收藏文章？星标颜色是什么意思？

在文章详情页底部点点赞、投喂右侧的五角星，打开收藏夹选择器，可同时勾选多个收藏夹。未收藏时星标灰色，收藏后黄色。第一次使用可在同一弹窗创建收藏夹。手机上点赞、投喂、收藏并排，星标在最右边。

## 收藏会通知作者吗？能看到一篇文章的被收藏数吗？

收藏不会通知作者，本站也不公开文章被收藏的次数。它用于整理自己的文章列表；表达喜欢可以点赞或投喂。

## 收藏夹在哪里管理？

工具箱 → 站务工具 → 我的收藏夹（`/favorite`），可以创建、改名、删除、导出和导入。收藏选择器右下角的"管理收藏夹 →"也能进入。

## 私密收藏夹和公开收藏夹有什么区别？

| 项目 | 私密收藏夹 | 公开收藏夹 |
|---|---|---|
| 可见范围 | 只有你自己 | 任何核心用户 |
| 6 位对外 ID | 没有 | 有，且为纯数字 |
| 分享二维码、文章引用、机器人读取 | 不支持 | 支持 |
| 导出 JSON、复制 | 支持 | 支持 |

创建时选"创建私密收藏夹"或"创建公开收藏夹"，创建后性质不能直接修改。私密收藏夹确实没有 6 位对外 ID。

## 怎么把私密收藏夹变公开，或把公开收藏夹变私密？

打开收藏夹，点"复制为私密收藏夹"或"复制为公开收藏夹"，得到所选性质的新收藏夹。这是改变性质的办法，原收藏夹仍保留。

## 能复制别人的公开收藏夹吗？复制后会同步更新吗？

能复制成自己的一份。复制保存点击时的标题和文章列表，是快照；以后原件和副本分别更新。原件新增、移出文章或删除，都不会同步到副本。需要新内容时重新复制。

## 怎么分享公开收藏夹？游客能打开吗？

公开收藏夹页显示 6 位 ID，可以生成分享二维码，也可以发 `https://raricy.com/favorite/123456`。打开收藏夹页面需要登录且是核心用户，游客无法阅读。机器人读取公开收藏夹也需要 core+ 账号。

## 怎么用收藏夹 ID 嵌入博客或剪贴板？

写 `[@123456]`，6 位必须全是数字。博客和云剪贴板正文会展开为卡片，显示标题、条目数和前 10 篇文章链接，更多文章有"查看全部"。每篇正文最多 3 张卡片；卡片里的文章标题不会再次当成引用解析。

评论和讨论保持字面量。对外文章的站外访客也不会展开收藏夹卡片。

## 怎么导出收藏夹 JSON？文件里有什么？

打开收藏夹点"导出 JSON"，私密和公开收藏夹都可以导出。文件含版本、标题和文章 ID / 标题 / URL，例如：

```json
{
  "version": 1,
  "title": "值得重读的几篇",
  "blogs": [
    {"id": "文章ID", "title": "文章标题", "url": "https://raricy.com/blog/文章ID"}
  ]
}
```

导出文件不含收藏夹 ID 或私密 / 公开标记，但里面的文章列表和标题会交给接收文件的人。

## 怎么导入收藏夹？会合并到原来的收藏夹吗？

在"我的收藏夹"点"选择文件"，选 JSON 后点"导入为私密收藏夹"或"导入为公开收藏夹"。每次导入都会新建，不合并旧收藏夹。文件里的收藏夹 ID 或公开标记会被忽略，以导入时的选择为准。

不存在或已删除的文章会跳过，结束后显示新增和跳过数量。每个收藏夹最多 1000 篇文章。

## 收藏夹有哪些数量和操作频率限制？

| 项目 | 上限 |
|---|---|
| 每个用户收藏夹数量 | 200 个 |
| 每个收藏夹文章数量 | 1000 篇 |
| 新建 / 复制收藏夹 | 20 次 / 小时 |
| 加入 / 移出文章 | 300 次 / 小时、1500 次 / 天 |
| 导入 | 10 次 / 小时 |

同一文章可进入多个收藏夹，仍受每夹 1000 篇的限制。删除收藏夹释放数量配额。

## 删掉收藏夹会删掉文章吗？

不会。收藏夹是一组文章链接，删除只移除你这边的收藏夹，不删除文章，也不影响他人的收藏夹或已复制的副本。

## 为什么某个 6 位收藏夹 ID 打不开？

先确认已经登录并具有 Core 及以上角色，再核对 6 位纯数字 ID。已删除的收藏夹无法打开；私密收藏夹没有这样的对外 ID。
