# 图床

## 图床是什么？谁能上传图片？

图床是站内图片托管工具，入口 `/image`。登录且通过邀请码认证的 Core 及以上用户可以上传，获得区分大小写的 10 位字母数字 ID，用直链分享或在正文中引用。

## 图床有哪些格式、大小、配额和频率限制？

| 项目 | 限制 |
|---|---|
| 支持格式 | PNG / JPEG / GIF / WebP / SVG |
| 单文件 | ≤ 10 MB |
| Core / 管理员配额 | 50 MB |
| 站长配额 | 100 MB |
| 上传频率 | 每小时 200 张，一次传多张按张数计 |
| 图片 ID | 10 位大小写字母和数字，区分大小写 |

配额按账号累计，删除图片立即释放配额。上传会核对文件实际内容，改扩展名不能绕过格式限制。

## 图床主页在哪里看已用空间和图片？

`/image` 顶部有"使用指南"。配额条显示已用和上限，超过 80% 会变色提醒；下面是拖拽或选择文件的上传区，再下面是图片网格，新上传的排在前面。

## 图床会压缩图片吗？怎么保留原图？

"压缩图片（减小文件体积，轻微损失画质）"默认勾选。压缩会等比缩小超过 2000px 的图片，并重新压缩位图；JPEG / WebP 质量约 85，PNG 无损压缩。GIF 和 SVG 不压缩；压缩后更大的保留原图。

取消勾选后原样存储。上传时有进度条，成功后图片网格刷新。

## 怎么复制图片 ID、查看大图和删除图片？

图片卡片显示缩略图、文件名、大小和 10 位 ID。悬停可选"复制 ID"、"新窗口打开"、"删除"。点击缩略图打开大图预览，点遮罩或按 `Esc` 关闭；预览里也能复制 ID。

## 图床直链怎么写？旧直链还能用吗？

直链是 `/api/images/<图片ID>/raw`，例如 `/api/images/AbCdEf1234/raw`。Markdown 写法：

```markdown
![图片说明](/api/images/AbCdEf1234/raw)
```

旧的 `/image/i/<图片ID>` 地址仍可转到新直链。旧文章若写死了老服务器的 IP 地址，需要手动改成当前站点链接。

## 图片直链能公开分享吗？为什么删除后裂图？

当前上传的图片默认公开，拿到直链的人无需登录即可访问，因此只应上传可以公开的图片。历史私有图片只有作者和站长可见。直链会缓存一年；删除后返回 404，原来引用它的文章会裂图。

## 怎么用图片 ID 嵌入博客、评论或讨论？

写 `[@AbCdEf1234]`，10 位 ID 会展开成站内图床图片，支持点击放大。博客中它与剪贴板、投票共用 50 处引用额度。评论和讨论也可点"从图床选择"，挑已有图片。

## 编辑器怎么上传图片或插入已有图片？

博客和剪贴板编辑器有"上传图片"和"插入引用"。新传或挑选已有图，插入的都是 `![文件名](/api/images/ID/raw)` 这种标准 Markdown 图片。可一次选多张或拖入多张，单次合计不超过约 11 MB，超过时分批上传。

编辑器直传只收 PNG / JPEG / GIF / WebP；SVG 先在 `/image` 上传，再用图片 ID 引用。

## 图床图片普通删除和永久删除有什么区别？

普通删除让图片退出列表、直链失效，并立即释放配额。站长可在管理页永久删除图片，永久删除不可恢复，并会通知上传者。

## 图床上传提示不支持格式或内容不匹配怎么办？

确认文件为 PNG / JPEG / GIF / WebP / SVG，实际内容和声明格式一致。把其他文件改名成图片扩展名仍会被拒绝。

## 图床提示存储空间不足怎么办？

到 `/image` 删除不用的图片，配额会立即恢复。Core 和管理员为 50 MB，站长为 100 MB。

## SVG 为什么打开后下载？

SVG 以附件下载，浏览器不会直接内联显示。这能防止文件中的脚本随站点页面执行。

## 博客里的图片裂图怎么办？

检查图片是否已删除、ID 是否正确，以及读者是否有权查看历史私有图片。已删除图片的直链返回 404，需要重新上传并更新正文中的引用。
