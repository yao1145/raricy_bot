# 内容引用语法

## 内容引用怎么写？各种 ID 分别是什么？

| 写法 | 引用内容 | 识别规则 |
|---|---|---|
| `[@123456]` | 公开收藏夹 | 6 位纯数字 |
| `[@a1b2c3d4]` | 云剪贴板 | 8 位字母数字 |
| `[@vOtE12345]` | 投票 | 9 位字母数字 |
| `[@AbCdEf1234]` | 图床图片 | 10 位字母数字 |
| `[@音频/AbCdEf1234]` | 音频播放器 | 带"音频/"和音频 ID |
| `[@合集/表情]` | 表情包 | 合集名 / 表情名 |
| `[@用户/张三]` | 用户名片 | 带"用户/"和用户名 |

字母数字 ID 区分大小写。6 位字母不是收藏夹；长度或字符不合规则的引用保留原文。内容 ID 内部空格可忽略，例如 `[@ a1b2c3d4 ]`。

## 博客、剪贴板、评论和讨论各支持哪些内容引用？

| 类型 | 博客和云剪贴板正文 | 评论和讨论 |
|---|---|---|
| 收藏夹 | 最多 3 张卡片 | 保留原文 |
| 云剪贴板 | 支持 | 每条消息只展开第一条 |
| 投票 | 支持 | 保留原文 |
| 图床图片 | 支持 | 最多 50 张 |
| 音频 | 最多 3 个 | 最多 3 个 |
| 表情包 | 保留原文 | 最多 30 个 |
| 用户名片 | 保留原文 | 最多 5 张 |

使用这些站内功能需要登录且有 Core 及以上角色。站外访客阅读公开文章时还有不同的展示范围。

## 博客和剪贴板的引用数量限制是多少？

剪贴板、投票、图床图片共用 50 处替换额度；收藏夹独立最多 3 张，音频独立最多 3 个，不占前面的 50 处。

需要读取内容的剪贴板、投票、收藏夹，一轮最多读取 50 个不同 ID；图片和音频不占读取额度。同一剪贴板引用多次只读取一次。未进入前 50 个读取候选的引用保持原文；进入候选但超过显示额度的也可能保持原文。

## 内容引用展开后能把正文撑到多长？

博客、云剪贴板的展开后正文总长度 ≤ 500,000 字符。放不下的整条引用保持字面量，不从中间截断；收藏夹卡片也计入这个长度。

站外文章中可展开的公开剪贴板最多 50 条，合计最多 500,000 字符，超过的仍保留原文。

## 为什么评论和讨论只展开一条剪贴板？超过 2000 字会怎样？

一条消息只展开第一条剪贴板，后面的 `[@8位ID]` 保留原文。展开的剪贴板正文超过 2000 字时截断，附"内容过长，已截断"和原剪贴板链接。博客正文的单条剪贴板不会这样截断，但受整篇 500,000 字符预算约束。

## 剪贴板相互引用或引用自己会无限展开吗？

不会。剪贴板只展开一层，替换进来的正文中再出现剪贴板引用会保持原文。替换进来的音频和收藏夹仍可展开，并受各自额度和总长度约束。

## 站外访客能看到对外文章里的哪些引用？

文章设为"凭链接可读"或"对外公开"后，未登录读者可看到公开图片、音频和公开剪贴板。私密剪贴板、投票、收藏夹保持原文，不变成内容或卡片。

准备给站外读者看的文章时，把必须读到的信息写成普通文字、公开图片或公开剪贴板。私密内容即使属于文章作者，也不会向访客展开。

## 怎么插入图床图片？评论里手写 img 标签有效吗？

从 `/image` 复制 10 位 ID，在正文写 `[@AbCdEf1234]`，会显示图片并支持点击放大。评论和讨论可直接点"从图床选择"挑已有图片。

评论和讨论中手写 `<img>` 会当普通文字，不能用来显示外链图片。正文中的站内图床引用能显示；博客正文允许手写 `<img>`。历史私有图只有作者和站长能取到，其他人看见裂图。

## 怎么嵌入云剪贴板？加载失败会显示什么？

从 `/clipboard` 列表或 `/clipboard/<ID>` 获取 8 位 ID，写 `[@a1b2c3d4]`。有权限时替换为正文，里面的 Markdown 正常排版。站内内容不存在、非公开且不属于你，或登录 / Core 权限不足时，可能显示 `[剪贴板 a1b2c3d4 加载失败]`。站外的私密剪贴板保持字面量。

## 怎么嵌入投票？投过和锁定后的组件有什么区别？

写 `[@vOtE12345]`，只在博客、云剪贴板展开。未投且未锁定时有选项与"投票"按钮，提交后就地刷新；已投或已锁定时显示总票数、各选项票数、百分比和进度条。

"查看详情"在新窗口打开 `/vote/<ID>`。站内加载失败时可能显示 `[查看投票]` 链接；评论、讨论和站外视图保留引用原文。

## 怎么嵌入公开收藏夹？私密收藏夹可以引用吗？

写 6 位纯数字，例如 `[@123456]`。博客、云剪贴板最多展开 3 张卡片，每张有标题、条目数、前 10 篇文章链接和"查看全部"。私密收藏夹没有对外 ID，不能引用。评论、讨论和站外视图都不展开收藏夹。

## 怎么嵌入音频？

写 `[@音频/AbCdEf1234]`，博客、剪贴板、评论、讨论四处均可显示播放器，每条正文最多 3 个。音频直链公开，站外读者也能播放。

## 怎么插入用户名片？会直接发送吗？

评论、讨论工具条的名片按钮可搜索用户名，选人后把 `[@用户/张三]` 插到光标处，草稿继续保留，不会自动发送。也可手写。展开后是带头像、头像框和用户名的行内名片，点开个人主页。

## 用户名片按用户名还是 ID？找不到用户会怎样？

名片认用户名，不是用户 ID；用户名注册后不可修改。一条消息最多 5 张，多出的保留原文。名字写错或用户不存在时也保留字面量。

名片选择器只搜索 Core 及以上用户；非核心账号的名片仍可手打 token。没有上传头像的人会显示系统生成头像。

## 用户名片和内容引用会产生 @ 通知吗？

不会。`[@用户/张三]` 名片、表情和其他内容引用都不算 @ 提及。要通知对方，用正常的 `@张三 `，用户名后接空白或行尾。

## 为什么“用户”和“音频”是保留合集名？

`[@用户/名字]` 用于名片，`[@音频/ID]` 用于音频。两者与表情语法形状相同，因此同名表情合集不会生效。

## 怎样在文中展示引用语法而不展开？

把引用放进行内代码或代码块，四处都保持原文。普通正文中 ID 写错、引用超额等情况也会留下字面量，先核对 ID、内容是否存在和使用场景。

## 编辑器可以选择引用并预览吗？

博客和剪贴板工具条的"插入引用"能选择图床、音频、剪贴板、投票、收藏夹。图片插入标准 Markdown 直链，其他类型插入相应 `[@…]`。预览和发布使用相同的引用规则；投票预览只读，无法提交，表情与名片在这些正文中始终不展开。

## 引用剪贴板会改掉保存的文章原文吗？

不会，保存的引用标记仍在文章原文里。阅读时替换成剪贴板 Markdown，并参与文章排版；引用内容中未闭合的代码块等格式会影响显示，嵌入前应检查。
