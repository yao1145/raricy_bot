# 云剪贴板

## 云剪贴板是什么？会读取我电脑上复制的内容吗？

云剪贴板是站内的 Markdown 内容管理与复用工具，入口是 `/clipboard`。里面保存的是你主动填写并提交的正文，不会读取或记录操作系统剪贴板里的内容。

## 谁能使用云剪贴板？

需要登录并通过邀请码认证，成为核心用户（Core）或更高角色。没有邀请码时可联系站长。

## 怎么查找和打开云剪贴板？

`/clipboard` 列出你创建的剪贴板，按创建时间倒序显示标题和 8 位 ID。顶部的搜索跳转框可以输入 ID，再点"前往"打开详情。也可以直接访问 `/clipboard/<ID>`。

## 怎么创建云剪贴板？标题和正文能写多长？

在 `/clipboard` 点"创建剪贴板"，填写标题和 Markdown 正文，选择是否公开，再点"提交"。成功后会跳到详情页。

| 项目 | 限制 |
|---|---|
| 每人最多创建 | 200 篇 |
| 标题 | 1–40 字符，必填 |
| 正文 | ≤ 50,000 字符，必填 |
| 是否公开 | 默认勾选，可取消 |

## 云剪贴板正文支持哪些排版？

支持标题、列表、粗体、斜体、引用、代码高亮、一键复制代码、GFM 表格、任务列表、图片点击放大和 LaTeX 数学公式。外部链接会在新标签页打开。图片可以用标准 Markdown 写法 `![图片说明](url)` 插入。

## 云剪贴板怎么写数学公式？

行内公式用 `$x^2$` 或 `\(x^2\)`；块级公式用 `$$E=mc^2$$` 或 `\[E=mc^2\]`。多行公式可以在两行 `$$` 之间使用 `cases`、`aligned` 等环境：

```markdown
$$
\begin{cases}
x > 0 & \text{正} \\
x < 0 & \text{负}
\end{cases}
$$
```

孤立的 `$`（例如价格 $5）不会被当成公式；代码块里的 `$` 也不会渲染。

## 云剪贴板详情页有哪些按钮？

作者能看到"编辑文章"和"删除文章"。"复制正文"复制原始 Markdown；"返回云剪贴板主页"回到列表；"返回上页"执行浏览器后退。

## 怎么编辑云剪贴板？能修改别人的内容吗？

只有作者本人可以编辑。在详情页点"编辑文章"，修改标题、正文或公开状态，再点"更新"保存并返回详情。

## 云剪贴板如何快捷保存和自动保存？

编辑时按 `Ctrl+S`（macOS 用 `Cmd+S`）保存，仍留在编辑页；右上角显示保存成功或失败提示。"自动保存（每分钟）"默认关闭，勾选后每隔 1 分钟保存一次，开关状态会在同一浏览器中保留。点击"更新"提交后自动保存停止。

## 公开云剪贴板和私密云剪贴板有什么区别？

公开剪贴板默认允许 Core 及以上成员凭 8 位 ID 查看；它没有公开列表，ID 是访问入口。公开内容被嵌进对外可读的博客后，站外读者也能读到。

私密剪贴板只有作者和站长能查看，其他人访问得到 403。他人无法通过博客引用读取私密内容；站外访客也不会展开私密剪贴板，即使文章作者引用的是自己的私密内容。

## 删除云剪贴板后能恢复吗？

删除后可联系站长恢复。普通删除会隐藏内容并使它退出正常访问，不是永久销毁。

## 怎么把云剪贴板嵌入博客？

复制剪贴板的 8 位 ID，在博客正文写 `[@abc12345]`。有权限时，这一处会替换成剪贴板完整 Markdown 正文，标题、列表和代码块等继续参与文章排版。ID 区分大小写，内部空格可以省略或保留，例如 `[@ abc12345 ]`。

## 博客引用云剪贴板有哪些数量和长度限制？

剪贴板、投票、图床图片共用每篇博客 50 处替换额度；收藏夹另有最多 3 张卡片，音频另有最多 3 个播放器。需要读取内容的剪贴板、投票、收藏夹一轮最多读取 50 个不同 ID，同一剪贴板反复引用只算一个；图片和音频不占这个读取额度。

引用展开后的正文总长度 ≤ 500,000 字符。放不下的整条引用保留原文，不从中间截断。超过读取候选或替换数量的引用也保留原文。

## 云剪贴板里再引用其他剪贴板会继续展开吗？

剪贴板引用只展开一层。替换进来的正文里再出现 `[@8位ID]` 会保留原文，包括引用自己或相互引用。替换进来的音频、收藏夹引用仍可展开，并受各自数量和整篇长度限制。

## 为什么博客里的云剪贴板引用没有显示？

先检查 ID 大小写、登录和 Core 认证、剪贴板是否存在，以及它是否公开或属于你。站内加载失败会显示 `[剪贴板 abc12345 加载失败]`。

超过 50 处替换、50 个读取候选或 500,000 字符总长度的引用会保留原文。站外访客只能展开公开剪贴板，私密剪贴板保持字面量。
