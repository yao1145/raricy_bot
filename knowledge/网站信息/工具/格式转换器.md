# 格式转换器

## 格式转换器在哪？文件会上传服务器吗？

入口 `/tool/convert`，在工具箱里。转换在你的浏览器和设备本地完成，原文件和结果不上传服务器。引擎已加载后可以断网使用。关闭或刷新页面前记得下载，服务器没有转换历史可供找回。

## 格式转换器怎么使用？

选择图片、音频、视频、文档 PDF、表格数据、文本字幕、电子书或压缩包类别，把文件拖到"添加文件"或点"选择文件"，在"设置输出"选择格式和参数，再点"开始转换"。一个任务可以包含多个文件。

文件和目标匹配后按钮才会启用，按钮下方会说明缺哪一步。结果可以预览、逐个下载，或点"打包下载全部成功结果"保存 ZIP。高级参数默认折叠，电脑上文件和设置并排，手机上依次排列。

## 转换器按扩展名识别文件吗？为什么某个目标不在菜单里？

转换器检查文件内容，改扩展名不能伪装成另一种格式。菜单只显示当前文件和设备真正支持的目标；浏览器无法编码的格式不会出现。计划中的功能不等于当前支持。

## 格式转换器八个能力区的大小和数量限制是什么？

| 能力区 | 支持的主要转换 | 上限 |
|---|---|---|
| 图片 | JPG / PNG / WebP / AVIF / BMP / TIFF / ICO / HEIC 互转，SVG 栅格化，动图拆帧 / 合成 | 单张 20MB、1600 万像素 |
| 音频 | MP3 / WAV / FLAC / OGG / M4A / AIFF 互转、换封装 | 20MB、5 分钟、双声道 |
| 视频 | 转 MP4 / MKV / WebM、提取音频、转 GIF、抽帧、提取字幕 | 100MB、2 分钟、1080p |
| 文档 / PDF | PDF 逐页图片、图片合成 PDF、取文字、合并 / 拆分 / 重排、压缩、扫描件 OCR | 50MB、300 页 |
| 表格数据 | CSV / TSV / XLSX / JSON / NDJSON / YAML / XML 互转 | 20MB、20 万行 |
| 文本字幕 | GBK / Big5 / Shift_JIS 等编码转换、SRT / VTT / ASS 互转 | 10MB |
| 电子书 | Markdown / HTML / TXT / DOCX 转 EPUB、EPUB 转回与解包 | 50MB |
| 压缩包 | ZIP / TAR / GZIP 互转与解包、RAR / 7Z 解包转 ZIP | 100MB、2000 个成员、解压后 500MB |

## 转换任务可以并行、取消或重试吗？

任务排队逐个执行，转换中可取消，再重试。输出总大小达到 64MB 时队列暂停，下载或丢弃已有结果后自动继续。

## 第一次音视频转换为什么要下载引擎？

音频、视频、动图转换首次需要下载约 30MB 的本地转换引擎。下载成功后在设备上运行；下载失败可重试，其他能力区仍可使用。

## “常用转换方案”和“固定配方”有什么区别？

"设置输出"下方的"常用转换方案（可选）"可自动填写目标和参数，例如手机照片分享、视频提声音、扫描资料取文字、表格给程序处理。它只显示当前类别的方案；添加文件前后都能选择，切换同类方案保留文件，手改参数后取消选中状态。

"转换并打包"中的固定配方把转换和打包组合起来，例如一组 HEIC 转 JPG 再打成 ZIP。

## 转换结果的“保留与损失说明”是什么意思？

它列出格式转换中保存和丢失的信息。例如 PNG 转 JPG 有损重编码、透明区域压到所选背景色、EXIF 不保留；XLSX 转 CSV 只保留公式计算结果和所选工作表；PDF 转图片失去文字层；RAR / 7Z 转 ZIP 不保留时间戳与文件属性。转换后按结果区说明检查。

## 格式转换器支持加密压缩包吗？

暂不支持。压缩包有成员数、解压总量、目录层级和压缩比限制，带 `..` 的成员路径会拒绝。

## 扫描件 OCR 结果能直接当原文用吗？

OCR 支持中英双语，可能识别错字，提取后需要校对。结果页也会提醒。

## 格式转换器能把 DOCX 真正排版成 PDF 吗？

目前没有真正的 DOCX 转 PDF。可以先转 Markdown / HTML；反向需求有 PDF 转 DOCX（图片型）。以当前菜单实际列出的方向为准。
