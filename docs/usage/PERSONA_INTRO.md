# 用 `/persona`，让机器人逐步了解你的交流习惯

如果你经常找机器人讨论同一类问题，又总要重复说明自己的背景和回答偏好，可以试试用户画像。
它把你确认过的信息整理成一段短文，让后续交流更贴近你的知识背景、兴趣和表达习惯。

比如，你已经熟悉 Python 基础，希望回答直接进入实现；讨论陌生领域时，你又希望先解释概念、
给出具体例子。这些差异都可以写进画像。机器人会据此调整说明的起点、篇幅与组织方式。

用户画像目前在 Linux 完整版开放，由站长启用并授权账号。所有管理操作都在你与机器人的私聊中完成。

## 从五个问题开始

在私聊发送：

```text
/persona
```

首次建档会先说明资料用途，再阅读你最近的 5 篇可访问博客，以及当前私聊里最近 50 条你本人发送的
有效文字。资料不足时会按实际数量继续；原始样本在内存中处理，资料与后续答案会交给当前模型服务。

机器人会根据已有信息问你 5 个问题，用来了解你熟悉的领域、兴趣、表达偏好和思考问题的习惯。
按问卷提示回答，可以逐题使用 `/persona answer <编号> <回答>`，也可以直接回复问卷消息按编号作答。

回答时，具体的例子很有帮助：

- “我熟悉 Python 和 SQL，但统计学还在入门。”
- “解释概念时先给一个例子，再给定义；写代码时先给可运行的方案。”
- “我最近关注摄影，希望讨论器材时考虑体积和预算。”

暂时不确定的偏好，也可以照实说明。画像会根据已有资料推测，有依据的判断才写进去；缺少依据的维度
可以留空。博客或私聊数量不足，也能继续建档。

## 保存之前，由你审阅

答完问题后，你会收到一段画像草稿，描述你的知识水平、兴趣、表达偏好与思维倾向。先读一遍，
尤其留意哪些判断不准确、哪些只是近期情况。

每次建档或编辑流程允许修改一次。建议把修改意见集中写清楚，例如：

```text
/persona revise 我对统计学只是入门；摄影是近期兴趣。回答优先简洁，需要推导时再展开。
```

机器人会展示修改后的版本。满意后，按提示确认草稿编号，或回复草稿消息“同意”。保存的是你已经看到
的确切版本。想结束本次流程，可以使用 `/persona cancel`。

以后发现画像需要调整，再发 `/persona edit` 开始新的编辑流程，每次仍有一次修改机会。

## 随交流更新，也能随时暂停

保存后，画像会随普通私聊逐步更新。机器人在回答送达后积累新的观察，达到更新条件时再调整，
你手动修改过的特征会优先保留。自动更新失败时，已有画像保持原样。

常用命令如下：

| 命令 | 用途 |
|---|---|
| `/persona` | 查看画像；首次建档或继续待办流程 |
| `/persona edit` | 手动修改 |
| `/persona off` | 停止使用与自动更新，并撤回公开副本；私有画像保留 |
| `/persona on` | 重新开启已有画像；尚未建档时开始访谈 |
| `/persona clear` | 预览清空操作，确认后清除画像并撤回公开 |

`/reset` 只重置短期对话，不删除画像。详细的流程、输入限制和全部命令见
[使用手册 §3.5](USAGE.md#35-用户画像-persona)。

## 默认私有，公开需要再次确认

私有画像只在你本人的私聊中参考。画像短文、特征及流程中的问答、草稿保存在私有 Markdown 中；
用于生成和回答的信息可能发送给模型服务，正文不进入运行日志或 SQLite。

如果你希望机器人在大区或博客评论的相关讨论中也能参考你的背景，可以使用 `/persona public`。
它会先展示准备公开的短文，确认后才发布。公开副本不包含访谈问答或证据；只有公开对话出现或精确提到
你时，才可能参与该轮回答。

私有画像更新不会自动修改公开副本。需要更新公开内容时，再次预览并确认；撤回使用 `/persona private`。
`/persona off` 同样会撤回公开，之后重新开启也保持私有。

建议先以私有方式使用，观察几轮回答是否符合你的习惯，再用 `/persona edit` 调整。你愿意公开哪些内容，
可以在公开预览时逐项审阅。
